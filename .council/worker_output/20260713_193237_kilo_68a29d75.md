## HUONG FIX

### Fix 1: insert_turn() them zone va zone_index (`clm_librarian_capture.py:426-458`)

Them `zone='Z1', source_type='session'` vao INSERT, va ghi `zone_index` sau insert:

```python

    writer, session_id, project, source_path, source_line_start, source_line_end,
    source_user_id, source_assistant_id, turn_index, user_timestamp, assistant_timestamp,
    user_prompt, assistant_response, prompt_sha256, response_sha256, content_hash,
    redacted, status, created_at, zone, source_type    -- + zone, source_type
) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, 'Z1', 'session')
```

Sau do:
```python
row_id = cur.lastrowid
conn.execute("INSERT OR REPLACE INTO zone_index(raw_turn_id, zone, subzone, ingested_at) VALUES(?,?,?,?)",
             (row_id, 'Z1', None, utc_now()))
```

### Fix 2: Chay 1 query correct backlog (da co turn Z3 sai)

```sql
UPDATE raw_turns SET zone='Z1', source_type='session'
WHERE writer IN ('claude','codex') AND COALESCE(zone,'Z3')='Z3';

INSERT OR REPLACE INTO zone_index(raw_turn_id, zone, subzone, ingested_at)
SELECT id, 'Z1', NULL, COALESCE(created_at, datetime('now'))
FROM raw_turns
WHERE writer IN ('claude','codex') AND id NOT IN (SELECT raw_turn_id FROM zone_index);
```

### Fix 3: sua ensure_api_tables() else branch (`clm_librarian_api.py:580-592`)

Them them dieu kien `OR COALESCE(zone,'')='Z3'` de catch ca default Z3:

```python
UPDATE raw_turns SET zone='Z1', source_type='session'
WHERE writer IN ('claude','codex')
  AND (COALESCE(NULLIF(TRIM(zone),''),'')='' OR COALESCE(NULLIF(TRIM(zone),''),'Z3')='Z3')
```
