## 2. DROPDOWN wZone BUG — CONFIRMED 🐛

### Location: Watch folder zone selector (`#wZone`) + Ingest zone selector (`#igZone`)

**Root cause (exact code in `loadZones()`):**
```javascript
// BUG: wZone và igZone thiếu placeholder option
const igZ = document.getElementById('igZone');
if(igZ) igZ.innerHTML = (r.zones||[]).map(function(z){
  return '<option value="'+esc(z.name)+'">'+esc(z.name)+'</option>';
}).join('');

const wZ = document.getElementById('wZone');
if(wZ) wZ.innerHTML = (r.zones||[]).map(function(z){
  return '<option value="'+esc(z.name)+'">'+esc(z.name)+'</option>';
}).join('');
```

**So sánh với các dropdown KHÁC** (fZone, distZone, g3zone, askZone) — những dropdown này **có** placeholder:
```javascript
// ĐÚNG: có placeholder
const opts = '<option value="">all zones</option>' + (r.zones||[]).map(...).join('');
```

**Hậu quả:**
- wZone dropdown default = Z1 (first zone trong array iteration)
- igZone dropdown default = Z1
- User có thể vô tình watch folder vào Z1 thay vì phải chọn zone đúng

**Fix:** Thêm `<option value="">-- chọn zone --</option>` hoặc `<option value="">all zones</option>` vào đầu wZone và igZone giống như các dropdown khác.
