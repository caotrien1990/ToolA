## B1 — wZone placeholder (P0 — [Q] ToolQ)

**Root cause:** `loadZones()` in ToolQ homepage inline JS builds wZone `<select>` without a blank default option.

**Current code** (ToolQ `/` page, inline `<script>`, in `loadZones()`):
```js
const wZ=document.getElementById('wZone');
if(wZ)wZ.innerHTML=(r.zones||[]).map(function(z){
  return '<option value="'+esc(z.name)+'">'+esc(z.name)+'</option>';
}).join('');
```

**Fix:**
```js
const wZ=document.getElementById('wZone');
if(wZ)wZ.innerHTML='<option value="">— chọn zone —</option>'+(r.zones||[]).map(function(z){
  return '<option value="'+esc(z.name)+'">'+esc(z.name)+'</option>';
}).join('');
```

**File:** `D:\0. TRIEN\1. DATA\DATA\5. VIBE APP\1. APP\21. ToolQ\bin\clm_librarian_api.py` — find the inline JS block that generates `loadZones()`, locate `wZ.innerHTML=`, insert the blank option.

**Impact:** Prevents silent misrouting of watched folders to default first zone. All future folder watches will require explicit zone selection.

## B3 — buildDynamicToolForm truncation (P0 — [A] Dashboard)

**Root cause:** The function body is truncated mid-return statement. The JS was likely cut during a template edit.

**Current code** (in `/` dashboard inline `<script>`):
```js
function buildDynamicToolForm(toolName) {
  const schema = TOOL_SCHEMA_CACHE[toolName];
  if (!schema) return null;
  const fieldNames = schema.accepted_fields?.length
    ? schema.accepted_fields
    : Object.keys(schema.properties || {});
  if (!fieldNames.length) return {warning: schema.warning || '', fields: []};
  return {
    warim();
}
```

**Fix:** Replace with complete function:
```js
function buildDynamicToolForm(toolName) {
  const schema = TOOL_SCHEMA_CACHE[toolName];
  if (!schema) return null;
  const fieldNames = schema.accepted_fields?.length
    ? schema.accepted_fields
    : Object.keys(schema.properties || {});
  if (!fieldNames.length) return {warning: schema.warning || '', fields: []};
  return {
    warning: schema.warning || '',
    fields: fieldNames.map(f => buildDynamicField(toolName, f, schema))
  };
}
```

**File:** The Python source that renders the `/` dashboard HTML. Search for `buildDynamicToolForm` in `orchestrator_server.py` or `orchestrator_ui.py` — it's part of a large f-string template. Fix the Python string that emits this JS block.

**Impact:** Restores all tool modal forms. Users can click any tool → fill params → run from UI.
