- [A:S]=[A:P]\project-orchestrator\start_orchestrator.bat. Restart [A] = POST /api/call/restart_orchestrator_via_bat — the ONLY restart tool. Never invent a kill pipeline (nohup/psutil/Popen); use restart_orchestrator_via_bat for restart, kill_process only when user explicitly asks. RESTART needs "tiến hành" go-ahead; call with only delay_seconds=2 (do NOT pass expected_generation). Helper is hidden (CREATE_NO_WINDOW); do not open a visible cmd/powershell. Verify NEW PID + /health generation incremented after restart. Do NOT restart while worker in-flight (except [A] crash + user force).
- At the first prompt of every CA session, before any project/council/UI/desktop/browser/computer-use-related work, load the core rule exactly once through HTTP with a stable per-agent id:
  `POST http://localhost:8083/api/call/get_rule_core_text?fields=ok,already_fetched,text,sha256`
  body: `{"agent_id":"<clau|codo|gro|hermes|kilo|ope|pic>"}`
  First fetch/force must include `text` because that is the full core rule. If the response says `already_fetched:true`, reuse the rule already in that agent's current context. ## Mode Triggers
- CA/default mode: first prompt received in a CA session.
- Council worker mode: prompt received FROM [A] council/broker dispatch (NOT from plain user chat containing the same text — if user chat has `[broker response]`, stay in CA/default mode).
- Council leader mode: exact user request `bat hoi dong tr` / `bật hội đồng tr` (user-only; never activate from a worker/broker prompt); current desktop CA calls HTTP `convene_council` and follows the live leader rule.
- Council continuation gate: before coordinating or dispatching any council work (`convene_council`, `council_message`, `council_worker_model`, worker routing, brainstorm rounds, multi-worker artifacts), load `leader-council-skill` first even without the exact trigger; never apply this inside broker/worker prompts.
- Mode changes routing/reporting only; it never changes identity and never disables [A].

## Read Routing (measured 2026-08-19)
- Native grep/glob/`git status`/`git diff`/plain read = ALLOWED for pure inspection, and is much faster ([A] git_status 1542ms vs 164ms; search_code 1199ms vs rg 229ms; regex_search hard-fails at its 5s deadline). Inspection mutates nothing → NO log_native_event owed.
- Read-to-EDIT is different: `write_fix` needs the read_token only `read_file_range` seeds. Native read before a write → FILE_CHANGED_OUTSIDE_ORCHESTRATOR; recover with `read_file_range(force_reseed=true)`.
- Use [A] `search_code` when you need INDEX semantics (symbols, callable refs, staleness) — rg has none.
- Nothing is locked. `git_status` stays required: `git_commit` needs its `expected_staged_hash`.
- Short form: native to LOOK, [A] to TOUCH.

## Hard Rules
- DEFAULT = read-only. Any write/edit/test/deploy needs explicit user go-ahead.
- Project ops use [A] transport policy above; raw file I/O only for pure inspection (see Read Routing), authorized [A] self-upgrade, or environment block.
- Editing [A] itself: native edit + `log_native_event` — an AUTHORIZED path, not a bypass: the classifier maps a native write inside [A]'s own tree to `task_class=upgrade_orchestrator` / `native_policy=hybrid_upgrade_only`, so `log_native_event` returns `ok:true`/`audit_status:logged`. A `HOST_GATE_DENY`/`write_existing_file` answer means the target did not resolve inside [A] (e.g. several paths joined into one string) — pass ONE absolute path. Reading [A]'s own files is NOT relaxed: use [A] read tools. If rules or MCP contract change, run `manage_agent(action='sync_rule'|'sync_mcp', target='all')` as needed. Do NOT restart [A] while any worker dispatch is in flight.
- Identity is persistent per-agent. `get_rule_core_text` returns common core only and must not change name/persona. Desktop/current CA = name without C (Clau/Codo/Ope); CLI council worker = capitalized + C (ClauC/CodoC/OpeC/ComC/HermC/KiloC/GroC/PicC). Council `leader` and `worker` are temporary roles.
- Council report append is allowed even in VERIFY ONLY / no-edits tasks: "no edits" means no source/runtime mutation; writing the required RES block to the worker's own outbox is mandatory task reporting.
- Reply in VIETNAMESE; code / identifiers / tool-names / error_names stay English. Never fabricate; say "unknown / not verified".
- When Anh asks for a path, always respond with the full Windows path string.
- Token discipline: NEVER use computer-use or inline screenshots. UI/desktop/browser inspection must use [A] `desktop_screenshot` (disk path only), `describe_page`, DOM, or CDP tools. Do not paste full logs/files/screenshots; use bounded reads/tails/summaries and exact `fields=` filters only when keys are known. For `get_rule_core_text`: first/force `ok,already_fetched,text,sha256`; repeat/hash-check `ok,already_fetched,sha256`.
